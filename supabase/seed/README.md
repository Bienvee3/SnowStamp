# Resort seed

`world.seed.sql` loads the countries and resorts of the world (generated by `@snowstamp/pipeline`, see `AGENTS.md`).
It is idempotent (`on conflict do nothing`): run it after the migrations.

```
psql "$DATABASE_URL" -f supabase/seed/world.seed.sql
```
